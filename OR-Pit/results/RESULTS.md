# OR-PiT results

All numbers are SI-SDRi in dB (oracle Hungarian matching over all output slots) unless noted; *est-count* scores only the slots the halting head keeps. Generated by `scripts/make_results.py` from the evaluation files listed at the end.

## Ablation (own test set: 1,000 test-clean mixtures, 2–5 speakers, WHAM! noise, 4 s)

| | Variant | Overall | 2 spk | 3 spk | 4 spk | 5 spk | Count acc. (τ=0.5) | Count acc. (val-cal. τ) | Est-count SI-SDRi (cal.) |
|---|---|---|---|---|---|---|---|---|---|
| A | v1 model (original spec), new training recipe | 2.72 | 2.78 | 2.80 | 2.69 | 2.60 | 24.8 % | 28.0 % (τ=0.55) | 2.07 |
| B | A + masks on frontend features (R2.3) | 2.81 | 2.89 | 2.89 | 2.79 | 2.68 | 24.1 % | 25.5 % (τ=0.57) | 2.05 |
| C | B + gated cgMLP (R2.2) + halting-aware matching (R2.5) | 2.71 | 2.86 | 2.84 | 2.66 | 2.49 | 30.4 % | 32.8 % (τ=0.67) | 2.41 |
| D | C + FiLM-TCN mask refinement (R2.4) = OR-PiT v2 | 3.94 | 4.34 | 4.14 | 3.80 | 3.48 | 29.8 % | 31.7 % (τ=0.58) | 3.64 |

## Final models

| Model | Params | Own test (2–5 spk) | 2 spk | Count acc. (τ=0.5) | Count acc. (val-cal. τ) | Est-count SI-SDRi (cal.) | Libri2Mix noisy | Libri2Mix clean | Libri3Mix noisy | RTF 8 s (GTX 1650) |
|---|---|---|---|---|---|---|---|---|---|---|
| OR-PiT v1 (6.1 h, original recipe) | – | 2.49 | 2.58 | 25.0 % | – | – | – | – | – | – |
| OR-PiT v2 (final) | 6.14 M | 4.33 | 4.85 | 29.9 % | 36.2 % (τ=0.71) | 3.57 | 3.11 | 2.20 | 2.69 | 0.198 |
| Conv-TasNet (2-spk specialist, same budget) | 5.05 M | 5.63 | 5.63 | – | – | – | 3.85 | 2.88 | – | 0.073 |

τ = halting threshold. *val-cal.* = the threshold that maximises count accuracy on the validation set (dev-clean), then applied unchanged to test. LibriMix columns use the calibrated threshold for counting but report oracle-matched SI-SDRi. Fairness note: oracle matching lets OR-PiT pick the best N of its 6 slots, while Conv-TasNet has exactly N outputs; the est-count column removes that advantage (only slots the halting head keeps are scored, missed speakers count as 0 dB).


## LibriMix test sets: raw input vs. input normalised to −19 dBFS

LibriMix mixtures are ~5 dB quieter than the training mixtures (median −24.8 vs −19.7 dBFS for 2 speakers, `scripts/level_stats.py`). *norm* rescales each input mixture to −19 dBFS before the model (SI-SDR is scale-invariant, so references are untouched).

| Model | Test set | SI-SDRi raw | SI-SDRi norm | Count acc. raw | Count acc. norm | Est-count raw | Est-count norm |
|---|---|---|---|---|---|---|---|
| OR-PiT v2 (final) | Libri2Mix noisy | 3.11 | 3.23 | 33.6 % | 0.5 % | 1.37 | 2.92 |
| OR-PiT v2 (final) | Libri2Mix clean | 2.20 | 2.36 | 30.0 % | 0.2 % | 0.67 | 2.03 |
| OR-PiT v2 (final) | Libri3Mix noisy | 2.69 | 2.89 | 3.3 % | 52.5 % | 1.16 | 2.19 |
| Conv-TasNet (2-spk specialist, same budget) | Libri2Mix noisy | 3.85 | 3.85 | – | – | – | – |
| Conv-TasNet (2-spk specialist, same budget) | Libri2Mix clean | 2.88 | 2.88 | – | – | – | – |

Reference (different budget): LibriMix paper, Conv-TasNet trained on train-360, Libri2Mix noisy 16 kHz max mode: 13.5 dB; Libri3Mix noisy: 10.9 dB (Cosentino et al., 2020, Table 4).
